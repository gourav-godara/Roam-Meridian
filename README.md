# 🌍 Roam Meridian

> Plan smarter. Travel together.

Roam Meridian is a collaborative travel planning platform that brings everything needed for a trip into one place. Instead of jumping between maps, notes, weather apps, and expense trackers, users can discover destinations, plan itineraries, collaborate with friends, and manage their trips from a single application.

This project is being built as part of a hackathon, but our goal is to make it feel like a real product rather than just another college project.

---

## Why we built this

Planning a trip with friends is surprisingly frustrating.

You search destinations on one website.

Save places in another app.

Discuss plans in a group chat.

Split expenses somewhere else.

Check the weather separately.

After a while, everything is scattered across different platforms.

We wanted to build something that keeps the entire journey, from discovering a destination to completing the trip, in one place.

---

## What you can do

### 🌎 Explore Destinations

Browse destinations with search, filters, ratings, estimated budgets, and categories.

---

### 🗺 Plan Trips

Create day-wise itineraries and organize your travel plans in one place.

---

### 👥 Collaborate

Invite friends to your trip so everyone stays on the same itinerary.

---

### 💰 Track Expenses

Keep a record of trip expenses and split them between travelers.

---

### ⭐ Reviews

Read reviews from other travelers or share your own experiences.

---

### 🌦 Weather

Check live weather information directly from the destination page.

---

### 🤖 AI Planner *(Work in Progress)*

Generate personalized travel plans based on destination, travel dates, budget, and preferences.

## Design Philosophy

We wanted the interface to feel clean, spacious, and easy to use.

Some products that inspired our design decisions include Airbnb, Apple, and Linear. We aren't trying to copy them, but we do admire their simplicity, consistent spacing, and focus on the user experience.

Our own design focuses on:

- Mobile-first layouts
- Large destination imagery
- Minimal UI
- Smooth interactions
- Reusable components

## Running the Project

Clone the repository

```bash
git clone https://github.com/your-username/roam-meridian.git
```

Install frontend dependencies

```bash
cd client
npm install
```

Install backend dependencies

```bash
cd ../server
npm install
```

Run the frontend

```bash
npm run dev
```

Run the backend

```bash
npm run dev
```
